# 🏨 LuxeHaven - Luxury Resort & Suite Reservation Web Application

[![Tech Stack](https://img.shields.io/badge/Stack-JavaScript%20%7C%20TailwindCSS%20%7C%20HTML5-blue.svg)](https://github.com/)
[![Responsive](https://img.shields.io/badge/Design-100%25%20Responsive%20Mobile--First-brightgreen.svg)](https://github.com/)
[![License](https://img.shields.io/badge/License-MIT-amber.svg)](https://github.com/)

A modern, responsive, high-performance web application engineered for luxury hospitality and hotel room reservations. Built with modern JavaScript architecture, mobile-first Tailwind CSS utility styling, dynamic filtering, real-time date calculations, and interactive booking modal dialogs.

---

## 🌟 Key Features

- **Dynamic Suite Catalog:** Real-time client-side rendering of rooms and suites categorized into Deluxe, Private Pool Villas, and Presidential suites.
- **Interactive Room Filtering:** Seamless tab-based category filtering with instant UI updates without page reloads.
- **Availability Search Engine:** Check-in / check-out validation logic ensuring valid date intervals and accurate room queries.
- **Dynamic Reservation Modal:** Interactive booking dialog with real-time total price calculation based on selected nights and guest count.
- **Mobile-First Responsive Design:** Fully optimized across ultra-wide monitors, laptops, tablets, and smartphones.
- **Modern UI/UX:** Clean typography, backdrop blur navigation headers, subtle hover interactions, and accessible form controls.

---

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+ Modules, DOM Events)
- **Styling:** Tailwind CSS (Modern Utility-First Design System)
- **Icons:** Lucide Icons
- **Typography:** Plus Jakarta Sans & Playfair Display (Google Fonts)
